Design foundation — v2 redesign, revised

Materials of the pharaohs, built for a modern storefront

Same logo, exact shape — recolored. A palette drawn from real Egyptian materials (lapis, gold, carnelian, turquoise, malachite) instead of literal icon cliches.

The concept

Five materials, not five random colors

Each color in this system is named for the material a pharaoh's court actually used — the story reads as jewelry and stone, not pyramids-and-palm-trees clip art. Lapis lazuli carries the dark, premium weight; gold is the precious accent, used sparingly; carnelian, turquoise and malachite give the semantic/status colors real identity instead of generic red/blue/green.

Lapis

Deep, dark foundation. Text, dashboard chrome, premium dark sections.

Gold

Precious accent. Primary highlights, focus states, key CTAs — used sparingly.

Carnelian

Warm secondary. Sale badges, secondary actions, danger states.

Turquoise

Faience blue-green. Info states, links, cool highlight moments.

Malachite

Deep green. Success states, delivered/confirmed signals.

Logo

Exact same shape — recolored, never redrawn

The crown, the wings, the wordmark: unchanged. Only the ink changes per context — lapis on papyrus, gold or cream on lapis. A cropped crown-only mark carries the brand at small sizes (sidebar, topbar, mobile header) where the full lockup would be illegible.

Typography

Bigger, tighter, more confident

Cairo stays the one typeface end to end (Arabic is the primary script, not a secondary one) — but the scale is bolder and display sizes carry slightly negative letter-spacing for a sharper, more current feel than the previous pass.

Numerals

Western digits only

0-9 everywhere — prices, dates, order counts, OTP codes — not Arabic-Indic numerals. Applied consistently across every screen in this canvas.

Shape

Sharper radii, pill-shaped actions

Tighter default radii than the previous pass (crisper, less "soft SaaS"), reserving the largest radius for hero/marketing moments only. Primary actions are full pill shapes — lapis fill is the default; gold is reserved for the accent moment, not the default button.
